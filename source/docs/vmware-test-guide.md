## 1. 准备工作

### 1.1 软件下载

- **VMware Workstation Pro**（免费个人版下载地址）：
  https://www.vmware.com/products/workstation-pro.html
- 安装完成后建议重启一次系统。

### 1.2 宿主机系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 64 位 或 Windows 11 |
| CPU 架构 | x86_64 |
| 内存 | 8 GB 起步（推荐 16 GB） |
| 磁盘空间 | 至少 60 GB 可用（含虚拟磁盘与快照） |
| 虚拟化支持 | BIOS 已开启 Intel VT-x 或 AMD-V |

### 1.3 检查 BIOS 虚拟化

> **重要**：未开启硬件虚拟化，VMware 无法启动 64 位客户机。

1. 重启电脑进入 BIOS/UEFI 设置
2. 找到以下选项并设为 **Enabled**：
   - Intel 平台：`Intel Virtualization Technology (VT-x)`
   - AMD 平台：`SVM Mode` 或 `AMD-V`
3. 保存退出，重启进入 Windows
4. 在任务管理器 → 性能 → CPU 中确认"虚拟化"显示为"已启用"

### 1.4 ISO 文件位置

ISO 输出在本仓库的 `out/` 目录：

```
Java Net Lava OS/
└── out/
    ├── jnl-os-YYYY.MM.DD-x86_64.iso       # 主镜像
    └── jnl-os-YYYY.MM.DD-x86_64.iso.sha256sum   # SHA256 校验
```

> 推荐在挂载前先校验完整性：
> ```powershell
> Get-FileHash .\out\jnl-os-*.iso -Algorithm SHA256
> ```
> 将输出与 `.sha256sum` 文件中的值比对。

## 2. 创建新虚拟机

按以下步骤在 VMware Workstation 中新建一个空白虚拟机（**先建空白机、再挂 ISO**，可避免 VMware Easy Install 误判引导方式）。

1. 打开 VMware Workstation。
2. 菜单 **文件 → 新建虚拟机**（快捷键 `Ctrl+N`）。
3. 选择 **"自定义（高级）"**，点击"下一步"。
4. **硬件兼容性**：选择 `Workstation 17.x`。
5. **安装客户机操作系统**：选择 **"稍后安装操作系统"**。
   > ⚠ 切勿在此处直接选择 ISO，否则 VMware 会触发 Easy Install，可能错误配置固件与磁盘。
6. **客户机操作系统**：选择 `Linux`。
   **版本**：选择 `其他 Linux 5.x 或更高版本 内核 64 位`。
7. **虚拟机名称**：填写 `Java Net Lava OS`。
8. **位置**：建议放在非系统盘，例如 `G:\VMs\JNL-OS`。
9. **处理器配置**：
   - 处理器数量：`2`
   - 每个处理器内核数量：`2`
   - （合计 4 线程；建议 8 线程或以上更佳）
10. **内存**：`4096 MB`（推荐 `8192 MB`，GNOME 桌面较占内存）。
11. **网络类型**：选择 **"使用网络地址转换（NAT）"**。
12. **I/O 控制器类型**：选择 `LSI Logic（推荐）`。
13. **磁盘类型**：选择 `NVMe` 或 `SCSI`。
14. **选择磁盘**：选择 **"创建新虚拟磁盘"**。
15. **磁盘大小**：`40 GB`（最小 `20 GB`，推荐 `40 GB`）。
16. **磁盘存储**：选择"将虚拟磁盘存储为单个文件"或"多个文件"（按需，单文件性能略好）。
17. 点击 **"完成"**。

## 3. 配置虚拟机（关键）

新建空白虚拟机后，必须修改以下配置才能正常启动 JNL OS。

### 3.1 挂载 ISO

1. 选中虚拟机 → **编辑虚拟机设置**。
2. 在硬件列表中选择 **CD/DVD (SATA)**。
3. 选择 **"使用 ISO 映像文件"**。
4. 点击 **"浏览"** 选择 `out/jnl-os-*.iso`。
5. 勾选 **"启动时连接"**。
6. 点击"确定"。

### 3.2 启用 UEFI 引导（重要）

> **关键**：JNL OS 默认以 Wayland 启动 GNOME，**必须使用 UEFI 固件**，否则 Wayland 可能无法工作。

1. **编辑虚拟机设置** → 切换到 **"选项"** 标签页。
2. 选中 **"高级"**。
3. 在右侧 **"固件类型"** 中选择 **UEFI**。
4. 点击"确定"。

> 💡 **如果该选项灰色不可选**：需要先在"硬件"标签页中 **移除硬盘**，然后回到"选项"修改固件为 UEFI，最后再 **添加硬盘** 重新挂上原虚拟磁盘。

### 3.3 加速 3D 图形（重要，GNOME 必需）

> **GNOME 桌面在 VMware 中运行必须开启 3D 加速**，否则会黑屏或极度卡顿。

1. **编辑虚拟机设置** → **显示器**。
2. 勾选 **"加速 3D 图形"**。
3. **图形内存**：设置为 `256 MB` 或更高（推荐 `512 MB`）。
4. **监视器数量**：`1`。
5. 点击"确定"。

### 3.4 显示器分辨率

1. **编辑虚拟机设置** → **显示器**。
2. 选择 **"指定监视器设置"**。
3. 任意监视器：`1920x1080`。
4. 点击"确定"。

### 3.5 可选：提升性能

如宿主机性能充足，可进一步优化：

- **处理器**：展开"虚拟化引擎"
  - 勾选 **"虚拟化 Intel VT-x/EPT 或 AMD-V/RVI"**
  - 勾选 **"虚拟化 CPU 性能计数器"**
- **内存**：提升至 `8192 MB` 或以上
- **CPU**：提升至 `4 核 8 线程` 或以上

### 配置参数速查表

| 配置项 | 推荐值 | 最小值 |
| --- | --- | --- |
| 处理器 | 2 核 4 线程 | 2 核 2 线程 |
| 内存 | 8 GB | 4 GB |
| 磁盘大小 | 40 GB | 20 GB |
| 图形内存 | 256 MB+ | 128 MB |
| 固件类型 | UEFI | UEFI（必选） |
| 3D 加速 | 开启 | 开启（必选） |
| 网络类型 | NAT | NAT |

## 4. 启动与体验

### 4.1 首次启动

1. 点击 **"开启此虚拟机"**。
2. 在启动菜单中选择默认项：**`Java Net Lava OS (x86_64, UEFI)`**。
3. 等待 Plymouth 启动动画完成（约 30 秒至 1 分钟）。
4. 自动进入 GDM 并**自动登录** `jnluser` 用户（密码 `jnlos`）。
5. 进入 GNOME 桌面。

> 💡 若启动菜单倒计时未选择，5 秒后会自动进入默认项。

### 4.2 桌面功能体验

桌面默认有 **3 个快捷方式**：

| 快捷方式 | 功能说明 |
| --- | --- |
| **JNL Player** | 启动 jnlp 音乐播放器 |
| **Install Java Net Lava OS** | 启动 archinstall 将系统安装到磁盘 |
| **主题切换** | 弹窗选择 12 套主题之一 |

### 4.3 主题切换

1. 双击桌面 **"主题切换"** 图标。
2. 在弹出的 zenity 列表中选择主题（12 套可选）：

| 主题名 | 风格描述 |
| --- | --- |
| JNL-Default | 深色蓝紫（默认） |
| JNL-Light | 浅色 |
| JNL-Ocean | 海洋蓝 |
| JNL-Forest | 森林绿 |
| JNL-Sunset | 日落橙 |
| JNL-Lavender | 薰衣草紫 |
| JNL-Rose | 玫瑰红 |
| JNL-Gold | 金色 |
| JNL-Midnight | 午夜黑 |
| JNL-Arctic | 北极白 |
| JNL-Magma | 岩浆红黑 |
| JNL-Aurora | 极光渐变 |

3. 点击 **"确定"**，主题（GTK3/GTK4/Shell/图标/壁纸）**立即应用**，无需重启。

### 4.4 音乐功能体验

1. 双击桌面 **"JNL Player"** 图标，启动 jnlp。
2. 播放器自动扫描音乐目录：
   ```
   ~/.local/share/jnl-os/music/
   ```
3. 内置示例音乐：`sample.jnl`。
4. 在歌曲列表中**双击歌曲**即可播放。
5. 顶栏右侧的音乐图标提供快速控制：
   - 上一首 / 播放暂停 / 下一首
   - 音量调节

### 4.5 QQ音乐下载体验

JNL OS 已在 Firefox 中预装 QQ音乐下载扩展：

1. 启动 **Firefox**。
2. 访问 **https://y.qq.com**。
3. 播放任意歌曲。
4. 页面右上角会出现 **"⚙️ Tool"** 按钮。
5. 点击按钮 → 选择 **"🎵 添加指定音乐到桌面音乐"**。
6. 等待下载与打包完成（扩展会通过 Native Messaging 调用 `jnlc pack` 打包为 `.jnl`）。
7. 自动保存到：
   ```
   ~/.local/share/jnl-os/music/
   ```
8. 在 JNL Player 中点击刷新按钮即可看到新下载的歌曲。

## 5. 安装到磁盘（可选）

如需将系统真正安装到虚拟机硬盘上（脱离 ISO 持久运行）：

1. 双击桌面 **"Install Java Net Lava OS"**。
2. 进入 `archinstall` 交互界面。
3. 按照引导选择：

| 配置项 | 推荐选择 |
| --- | --- |
| 磁盘分区 | `/dev/sda` 整盘 |
| 文件系统 | `ext4` 或 `btrfs` |
| 引导加载器 | `grub` |
| 用户名 / 密码 | `jnluser` / `jnlos` |
| 桌面 | GNOME（预置） |
| 语言 locale | `zh_CN.UTF-8`（预置） |
| 镜像源 | 清华 TUNA（预置） |

4. 等待安装完成（约 10–30 分钟）。
5. 安装结束后选择 **重启**。
6. 重启前请通过 **虚拟机设置 → CD/DVD → 取消挂载 ISO**，确保从硬盘启动。

> 💡 也可在终端执行以下命令启动安装：
> ```bash
> sudo /usr/local/bin/install-jnl-os.sh
> ```

## 6. 常见问题

### Q1: 启动黑屏或卡在 Logo

- ✅ 检查是否启用 **UEFI 引导**（见 [3.2](#32-启用-uefi-引导重要)）。
- ✅ 检查 **3D 加速**是否开启（见 [3.3](#33-加速-3d-图形重要gnome-必需)）。
- ✅ 将**显卡内存**提升至 `256 MB` 以上。

### Q2: 桌面很卡

- ✅ 增加虚拟机内存到 `8 GB`。
- ✅ 增加 CPU 核心数（推荐 4 核 8 线程）。
- ✅ 关闭动画效果：安装并打开 GNOME Tweaks → 外观 → 关闭动画。
- ✅ 确认已开启 3D 加速。

### Q3: 无法上网

- ✅ 检查虚拟机网络设置为 **NAT**。
- ✅ 在虚拟机终端执行：
  ```bash
  sudo systemctl restart NetworkManager
  ```
- ✅ 检查宿主机网络是否正常。

### Q4: 分辨率不对

- ✅ 安装后运行：
  ```bash
  sudo pacman -S open-vm-tools
  ```
  并重启虚拟机。
- ✅ 在 GNOME 设置 → 显示器中调整分辨率。

### Q5: 安装失败

- ✅ 确认磁盘大小至少 `20 GB`（推荐 `40 GB`）。
- ✅ 检查 ISO 完整性：
  ```bash
  sha256sum jnl-os-*.iso
  ```
  将输出与 `.sha256sum` 文件比对。
- ✅ 确认安装时未错误选择只读的 Live 设备。

### Q6: Wayland 不工作

- ✅ 编辑 `/etc/gdm/custom.conf`，将 `WaylandEnable=false` 改为 `true`，然后重启 GDM：
  ```bash
  sudo systemctl restart gdm
  ```
- ✅ 或在 GDM 登录界面右下角齿轮处选择 **"GNOME on Xorg"** 作为兜底。

## 8. 与宿主机共享文件

### 8.1 安装 VMware Tools

在虚拟机终端执行：

```bash
sudo pacman -S open-vm-tools
sudo systemctl enable --now vmtoolsd
```

安装后支持：自动分辨率调整、剪贴板共享、拖拽文件。

### 8.2 拖拽

安装 `open-vm-tools` 后即支持宿主机与虚拟机之间的文件拖拽。

### 8.3 共享文件夹

1. VMware 设置 → **选项** → **共享文件夹**。
2. 选择 **"总是启用"**。
3. 点击 **"添加"** → 选择宿主机目录 → 命名。
4. 在虚拟机内访问路径：
   ```
   /mnt/hgfs/<共享文件夹名>
   ```

## 9. 退出与清理

### 9.1 正常关机

在 GNOME 桌面右上角菜单 → **关机**。

### 9.2 强制关机

如系统无响应，使用 VMware 菜单：**电源 → 关闭电源**。

### 9.3 删除虚拟机

右键虚拟机 → **从磁盘中删除**，将一并删除虚拟磁盘文件。

> 💡 建议在删除前先 **移除快照**，释放磁盘空间。

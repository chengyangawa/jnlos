# 安装指南

## 系统要求

| 项目 | 最低要求 | 推荐配置 |
|------|----------|----------|
| CPU | x86_64 | 4核以上 |
| 内存 | 2GB | 4GB以上 |
| 磁盘 | 10GB | 30GB以上 |
| 显卡 | 支持 OpenGL | 支持 Wayland |

## 制作启动盘

### Windows

1. 下载 ISO 文件并合并分卷
2. 使用 Rufus 或 Etcher 写入 U 盘

### Linux/macOS

```bash
# 合并分卷
cat jnl-os-1-0-32-1.0.32-x86_64.iso.part* > jnl-os-1-0-32-1.0.32-x86_64.iso

# 写入 U 盘（请替换 /dev/sdX）
dd if=jnl-os-1-0-32-1.0.32-x86_64.iso of=/dev/sdX bs=4M status=progress
```

## 安装步骤

### 步骤 1：启动系统

1. 将 U 盘插入电脑并从 U 盘启动
2. 开机动画后直接进入图形化安装向导

### 步骤 2：语言选择

选择中文或其他语言，点击下一步。

### 步骤 3：许可协议

阅读许可协议并勾选同意，点击下一步。

### 步骤 4：安装类型

- **自动分区**：系统自动划分 EFI/BIOS Boot、根分区和交换分区
- **手动分区**：自定义分区布局

### 步骤 5：磁盘选择

选择要安装系统的磁盘，点击下一步。

### 步骤 6：用户配置

- 用户名：默认为 `jnluser`
- 用户密码
- 根密码

### 步骤 7：安装确认

确认安装信息，点击开始安装。安装过程将自动完成，包括：

1. 磁盘分区和格式化
2. 文件系统创建
3. 复制系统文件（进度条显示）
4. 安装 GRUB 引导程序
5. 配置系统

### 步骤 8：完成安装

安装完成后点击重启，移除 U 盘，系统将自动登录进入桌面。

## 安装后配置

### 更新系统

```bash
sudo pacman -Syu
```

### 安装额外软件

```bash
sudo pacman -S git vim neovim
```

## 常见安装问题

### BIOS 模式下安装失败

确保磁盘使用 GPT 分区表并包含 BIOS Boot 分区（1MB，ef02 类型）。

### 网络连接问题

安装程序会自动连接可用的 WiFi 网络。如果连接失败，请检查网络设置。

### 磁盘空间不足

安装需要至少 10GB 可用空间。

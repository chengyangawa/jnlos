# 浏览器扩展

## 概述

JNL OS 提供浏览器扩展，支持从 QQ 音乐等平台一键下载歌曲并打包为 `.jnl` 格式。

## 功能特性

- 一键下载歌曲并自动打包为 `.jnl` 文件
- 自动获取封面图片和歌词
- 支持批量下载
- 自动保存到音乐库
- 支持 QQ 音乐平台

## 安装方法

### Firefox

1. 打开 Firefox 浏览器
2. 访问扩展商店
3. 搜索 "JNL Downloader"
4. 点击安装

### Chrome/Chromium

1. 打开 Chrome/Chromium 浏览器
2. 访问 Chrome 网上应用店
3. 搜索 "JNL Downloader"
4. 点击添加到 Chrome

### 手动安装

1. 下载扩展 ZIP 文件
2. 解压到本地目录
3. 在浏览器中打开扩展管理页面
4. 启用开发者模式
5. 点击加载已解压的扩展程序
6. 选择解压后的目录

## 使用方法

### 下载单首歌曲

1. 打开 QQ 音乐网站
2. 找到要下载的歌曲
3. 点击扩展图标
4. 在弹出的菜单中选择下载当前歌曲
5. 歌曲将自动打包为 `.jnl` 文件并保存到音乐库

### 批量下载

1. 打开 QQ 音乐专辑或歌单页面
2. 点击扩展图标
3. 选择下载全部歌曲
4. 扩展将依次下载每首歌曲并打包

### 下载设置

1. 点击扩展图标
2. 选择设置
3. 配置以下选项：
   - 保存路径：默认 `~/Music/JNL/`
   - 音频质量：标准/高/无损
   - 自动下载歌词：开启/关闭
   - 自动下载封面：开启/关闭
   - 批量下载并发数：1-5

## 扩展权限

扩展需要以下权限：

| 权限 | 用途 |
|------|------|
| tabs | 访问当前标签页 |
| webRequest | 拦截网络请求获取音频链接 |
| downloads | 管理下载 |
| storage | 保存设置 |
| activeTab | 访问活动标签页 |

## 常见问题

### 无法下载歌曲

- 确保已登录 QQ 音乐账号
- 检查网络连接
- 更新扩展到最新版本

### 下载的歌曲无法播放

- 检查音频文件是否完整
- 使用 `jnl-validate` 验证 `.jnl` 文件
- 确保安装了相应的解码器

### 歌词不显示

- 某些歌曲可能没有歌词
- 尝试手动添加歌词

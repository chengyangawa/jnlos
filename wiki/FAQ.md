# 常见问题

## 系统安装

### Q: 安装需要多少磁盘空间？

A: 至少需要 10GB 可用空间，推荐 30GB 以上。

### Q: 支持哪些启动模式？

A: 支持 BIOS 和 UEFI 两种启动模式。BIOS 模式下使用 GPT 分区表时需要创建 1MB 的 BIOS Boot 分区。

### Q: 安装过程中网络连接失败怎么办？

A: 
1. 检查网络连接
2. 切换到其他 WiFi 网络
3. 确保网络稳定后重试

### Q: 安装后无法启动怎么办？

A: 
1. 检查 BIOS/UEFI 设置，确保从正确的磁盘启动
2. 检查 GRUB 是否正确安装
3. 使用 Live CD 修复引导

## 桌面使用

### Q: 如何切换主题？

A: 打开系统设置 → 外观 → 主题，选择喜欢的主题即可。

### Q: 如何安装新软件？

A: 使用 pacman 包管理器：

```bash
sudo pacman -S 软件包名称
```

### Q: 如何设置中文输入法？

A: JNL OS 默认预装 Fcitx5 中文输入法，按 `Ctrl+Space` 切换输入法。

### Q: 如何连接 WiFi？

A: 点击顶栏的网络图标，选择可用的 WiFi 网络并输入密码。

### Q: 如何调整屏幕分辨率？

A: 打开系统设置 → 显示，选择合适的分辨率。

## 音乐播放器

### Q: 如何添加音乐？

A: 点击菜单 → 文件 → 添加文件夹，选择音乐文件夹即可。

### Q: 如何下载歌曲？

A: 使用浏览器扩展从 QQ 音乐等平台下载，歌曲将自动保存为 `.jnl` 格式。

### Q: 歌词不显示怎么办？

A: 
1. 确保 `.jnl` 文件包含歌词信息
2. 手动添加歌词：右键歌曲 → 编辑歌词

### Q: 无法播放音乐怎么办？

A: 
1. 确保安装了 GStreamer 插件
2. 检查音频文件格式是否支持
3. 重启音乐播放器

## 主题系统

### Q: 如何创建自定义主题？

A: 
1. 复制现有主题目录到 `~/.themes/`
2. 修改主题文件
3. 在系统设置中应用自定义主题

### Q: 主题切换后图标不变怎么办？

A: 重启系统或重新登录即可。

### Q: 如何安装其他图标主题？

A: 使用 pacman 安装：

```bash
sudo pacman -S papirus-icon-theme arc-icon-theme
```

## 系统维护

### Q: 如何更新系统？

A: 

```bash
sudo pacman -Syu
```

### Q: 如何清理系统缓存？

A: 

```bash
sudo pacman -Sc
```

### Q: 如何查看系统信息？

A: 打开系统设置 → 关于，查看系统详细信息。

### Q: 如何创建新用户？

A: 

```bash
sudo useradd -m -G wheel 用户名
sudo passwd 用户名
```

## 常见错误

### Q: "GRUB安装失败"错误

A: 在 BIOS 模式下使用 GPT 分区表时，需要创建 1MB 的 BIOS Boot 分区（ef02 类型）。

### Q: 安装过程中进度条停在 0%

A: 确保网络连接稳定，等待文件复制完成。

### Q: 音乐播放断断续续

A: 降低音乐播放器进程优先级或增加音频缓冲区。

### Q: 无法连接 WiFi

A: 确保 WiFi 驱动已正确安装，检查网络设置。

## 硬件兼容性

### Q: 支持哪些显卡？

A: 支持 NVIDIA、AMD 和 Intel 显卡。NVIDIA 用户可能需要安装专有驱动。

### Q: 如何安装 NVIDIA 驱动？

A: 

```bash
sudo pacman -S nvidia nvidia-lts
```

### Q: 笔记本电脑无法调节亮度怎么办？

A: 尝试添加内核参数 `acpi_backlight=vendor`。

### Q: 触控板无法使用怎么办？

A: 确保安装了 `libinput` 驱动，检查触控板设置。

## 性能优化

### Q: 如何优化系统性能？

A: 
1. 启用 zram 交换
2. 禁用不必要的服务
3. 减少桌面特效
4. 使用轻量级应用

### Q: 如何查看系统资源使用情况？

A: 使用 `top` 或 `htop` 命令查看 CPU 和内存使用情况。

### Q: 如何禁用开机启动程序？

A: 打开系统设置 → 开机启动，取消勾选不需要的程序。

## 数据备份

### Q: 如何备份系统？

A: 使用 rsync 备份重要文件，或使用 Clonezilla 克隆系统盘。

### Q: 如何备份音乐库？

A: 复制 `~/Music/JNL/` 目录到外部存储设备。
